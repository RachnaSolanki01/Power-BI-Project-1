# Power BI Sales Dashboard

## Project Overview
This project is an interactive Power BI dashboard created using the **Sample - Superstore** dataset. The dashboard provides an overview of sales and profit performance and allows users to explore the data using interactive filters and slicers.

## Dashboard Pages

### Page 1 – Sales Overview
The first page provides a high-level overview of business performance.

**Visuals included:**
- Total Sales card
- Total Profit card
- Total Quantity card
- Average Discount card
- Top 5 Sub-Categories by Sales
- Sales by Region
- Region slicer
- Category slicer

### Page 2 – Sales and Profit Analysis
The second page focuses on sales trends and category-wise profit analysis.

**Visuals included:**
- Sales Trend Over Time – Line Chart
- Total Profit by Category – Column Chart
- Region slicer

## Key Insights
- Sales performance can be analyzed over time using the yearly sales trend.
- Profit can be compared across different product categories.
- The Top 5 Sub-Categories visual highlights the strongest-performing sub-categories by sales.
- Region and Category slicers make the dashboard interactive and allow users to filter the displayed data.

- Data visualization

- Visual formatting

## How to Use
1. Open the Power BI `.pbix` file in Microsoft Power BI Desktop.
2. Navigate between Page 1 and Page 2.
3. Use the Region and Category slicers to interactively filter the visuals.
4. Hover over charts to view additional information through tooltips.
